# Field Note template

Title and concrete question

Author / publisher: use the actual accountable author, never invent an author or an institutional affiliation.
Published date / updated date / version / canonical URL

## Question
One specific question about Singapore AI.

## Structure observed
Explain the pattern as interpretation, with clear boundaries.

## Public evidence
For each observation: primary-source URL, publication date when known, access date, factual observation, and a separate interpretation. Recheck changed claims before a new release.

## What remains unknown
Coverage gaps, evidence limitations, and missing organisations.

## Related organisations
Stable Navigator records; do not imply partnership or endorsement.

## Sources
Full primary-source links. No unsourced numbers.

## Version history
Record substantive claim changes and corrections separately from layout changes.

## Publication outputs
Web page, copyable citation, PDF brief with source URLs, and a print layout. Update each together.
